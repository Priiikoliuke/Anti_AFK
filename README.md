# Хеллоу мабой
Это анти-афк скрипт, чтоб ебанный антиафк не кидал на спавн

## Как же запустить это дерьмо:

1. Нужно скачать архив этот весь, для этого:
   Сверху есть зеленая кнопка Code -> В ней надо нажать Download ZIP, после распаковать куда удобно (будем далее за пример брать рабочий стол)

2. Нужно установить зависимости, для этого открываем ебанный CMD и в нем сначала переходим в директорию где папка распакована, если на рабочий стол сделал - просто скопируй и вставь, все последующие действия делаются тоже в этой CMD:
   ```bash
   cd Desktop/Anti_AFK/
   ```
3. Далее нужно установить зависимости (все также в CMD):
   ```bash
   python3 -m pip install -r requirements.txt
   ```

3. И наконец стартуем это дерьмо:
   ```bash
   python3 Anti_AFK.py
   ```

## Далее можно просто запускать так:

В CMD:
   ```bash
   python3 Desktop/Anti_AFK/Anti_AFK.py
   ```
